# Redbelly Network DAO

Public GitHub organisation for the **Redbelly Network DAO Community Task Board**.

This organisation holds the public archive of selected and paid Task Board deliverables. Each winning submission is published in its own repository with a `NOTICE.md` that records the task, cycle, and contributor credit.

## Public transparency

- [Public Transparency Ledger](https://taskboard.redbellydao.network/ledger)
